What I build

I'm a final-year Computer Science student who builds end-to-end machine learning pipelines and Python backends, not just notebooks. My Job Market Dashboard pulls live postings from the Adzuna API, cleans and stores them in Supabase, and trains a Ridge regression model to predict salaries — currently at 0.112 RMSLE. My House Prices project compares four models (Ridge, XGBoost, LightGBM, GradientBoosting) across 79 features and 1,460 samples with 5-fold cross-validation, landing at the same 0.112 RMSLE.

This portfolio itself is a full-stack Flask and Supabase application with an admin panel for managing projects and an LLM-powered chatbot (Groq, Llama 3.1) that answers questions about my work in natural language — not a static template.

How I work

Data structures aren't just coursework to me — my Library Management System uses a Binary Search Tree for book lookups, a queue for the waiting list, and a set for the collection, because those were the right tools for the job, not because a syllabus asked for them. I read the problem first and reach for the structure or model that actually fits, then validate it with real metrics instead of assuming it worked.

I'm NAVTTC-certified in AI & Machine Learning and currently completing Saylani's AI & Data Science program, covering EDA, ML pipelines, and deep learning fundamentals with TensorFlow.

What's next

I'm looking for an AI/ML Engineer or Python Backend Developer role where I can take pipelines like these from personal projects to production systems — and keep shipping things that are measured, not just demoed.
